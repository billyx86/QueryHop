QueryHop Options

Turn this on to enable all search redirects.

or

Enter the full URL of the engine you'd like to use. This must start with http(s):// and contain %s as a placeholder for the query.

Bypasses normal URL checks (http/https prefix and the %s placeholder) for the redirect target. Some URL schemes (for example javascript:) are always rejected, even in this mode. Use with caution.

Keeps a short local trail of redirects: which engine matched, whether validation is disabled, and any blocked-scheme attempts. Search terms are not recorded — only a short, non-reversible fingerprint of each search is kept, and credential-looking URL parameters are redacted. Stored only in this browser session (cleared when the browser exits) and never sent anywhere. 

Debug log is empty.
